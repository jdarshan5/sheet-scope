# @jdarshan5/sheet-scope

Scoped, lazily-mounted, typed sheet manager for @gorhom/bottom-sheet

## Installation


```sh
npm install @jdarshan5/sheet-scope
```


## Usage


```js
import { multiply } from '@jdarshan5/sheet-scope';

// ...

const result = multiply(3, 7);
```
